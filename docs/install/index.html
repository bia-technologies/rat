Установка расширения RAT

В этом документе описывается процесс установки расширения RAT. Это расширение необходимо для того, чтобы предоставить внешним системам (например, Vanessa Automation) возможность взаимодействовать с данными вашей информационной базы 1С:Предприятие через HTTP-сервис.

Системные требования​

  • Vanessa Automation 1.2.036+
  • 1С:Предприятие 8.3.20+

Получение релиза расширения​

Расширение вы можете скачать со страницы релизов GitHub, файл .cfe.
Или собрать из исходников.

Способы установки​

Существует несколько способов установить (или обновить) расширение в вашу информационную базу 1С.

Установка через Конфигуратор​

Этот способ является стандартным для работы с расширениями в 1С.

  1. Запустите 1С:Предприятие в режиме "Конфигуратор" для той информационной базы, куда вы хотите установить расширение.

  2. Откройте список расширений: В меню выберите "Конфигурация" → "Расширения конфигурации".

    Параметры нового расширения оставляем по умолчанию и нажмите "Ok"

  3. Загрузите ранее скачанный файл расширения RAT.cfe

    Подтвердите замену расширения.

  4. Настройка свойств расширения: После добавления или обновления, выберите расширение "RAT" в списке и убедитесь, что сняты следующие галочки:

    • Безопасный режим
    • Защита от опасных действий

    Пояснение: Снятие этих галочек необходимо для того, чтобы расширение RAT могло выполнять все предусмотренные им функции и выполнение определенных операций на сервере. Однако, это также означает, что расширение получает больше прав в системе.

  5. Обновите конфигурацию базы данных (F7 или кнопка "Обновить конфигурацию базы данных" на панели инструментов).

Дополнительные инструкции по загрузке расширения​

  • Через конфигуратор
  • Для конфигураций на базе БСП
  • В режиме предприятия

Публикация HTTP-сервиса RAT​

После установки расширения, если вы планируете, чтобы к вашей информационной базе 1С можно было обращаться извне (например, для интеграции с другими системами или для запуска тестов Vanessa Automation, работающей на другом компьютере), необходимо опубликовать HTTP-сервис, предоставляемый расширением RAT. Эту операцию достаточно выполнить один раз; при обновлении расширения переопубликовывать сервис не нужно.

Инструкция​

Для детального пошагового руководства по публикации расширения см.

  • Публикация расширения RAT на IIS - инструкция для IIS (Windows)
  • Публикация расширения RAT на Apache - инструкция для Apache (Windows/Linux)
  • Официальная инструкция 1С

После публикации адрес сервиса будет выглядеть примерно так: http://[АдресВашегоЛокальногоСервера]/[ИмяПубликации]/hs/test-api (например, http://localhost/infobase_name/hs/test-api).
